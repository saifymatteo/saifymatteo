# Animations built on the `motion` library

The portfolio's animations (scroll reveals, hero entrance, page-transition fade) are built on the `motion` package (the framer-motion successor, React 19 compatible) rather than hand-rolled CSS + IntersectionObserver. The site aims for "small and subtle", and `motion` gives whileInView ergonomics, consistent easing/duration via a global `MotionConfig`, and built-in `prefers-reduced-motion` handling that a CSS-only approach would need to re-implement per element. Micro-interactions (card lift, link underline, arrow nudge) deliberately stay in plain CSS transitions so the motion runtime isn't paying for trivial hovers. If the dependency ever feels heavy, the `Reveal` component and `template.tsx` fade are the only motion touchpoints to replace.
